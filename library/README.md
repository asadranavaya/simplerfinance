# Shared rule library seed

This directory contains the repository-owner-managed v1 icon/rule catalog. Fresh installations import it locally and idempotently; matching administrator-created rules are never overwritten.

- `manifest.json` identifies the schema/library version and future signature.
- `rules.json` contains bounded declarative matching rules.
- `icons/` contains normalized 32, 64, and 128 pixel WebP variants.

The bundled images originated as administrator-approved community submissions.
